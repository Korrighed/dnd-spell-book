## Contexte

Vous êtes mandatés comme développeurs front-end juniors dans une agence web spécialisée en *datavisualisation* créative. Votre mission est de concevoir une application web interactive et visuellement attractive qui permet d'explorer des données issues d'une API publique.

L'application devra combiner :

- React ou Vue.js pour la structure,
- Three.js pour une visualisation 3D interactive,
- une API publique (parmi [Public APIs](https://github.com/public-apis/public-apis) ou [data.gouv.nc](https://data.gouv.nc)) comme source de données.

## Objectif

Proposer une navigation fluide permettant d'interagir avec les données (filtrer, zoomer, survoler, cliquer, etc.), avec une représentation **responsive** et visuellement attrayante.

### Exemples de projets réalistes (6 jours de travail)

- **Explorateur des films populaires :** affichage de jaquettes de films en 3D sur un mur interactif (API OMDB ou TMDB).
- **Galerie 3D d'œuvres d'art :** exposition virtuelle en cube/galerie avec navigation clavier/souris (API Metropolitan Museum of Art).
- **Explorateur spatial simplifié :** planètes du système solaire avec quelques infos récupérées (API NASA Open Data).

Ces idées sont volontairement contenues et faisables en une semaine de travail, tout en permettant de montrer créativité et compétences techniques.

## Contraintes

- Utilisation de Three.js (scène, caméra, rendu 3D interactif).
- Consommation d'au moins une API publique.
- Interface réalisée en React ou Vue.js.
- Navigation interactive (menus, filtres, clics sur objets 3D).
- Site responsive et attractif visuellement.
- Déploiement sur [Netlify](https://www.netlify.com/).
- Code versionné sur [GitHub](https://github.com/) (propre et structuré).
- En cas de problème de CORS : possibilité de copier les données dans le repo en local.
